# 김밥천국 레드 (KIMBAB HEAVEN RED)

김밥천국의 매운맛 서브 브랜드 '김밥천국 레드'를 가정해 기획부터 디자인, 퍼블리싱까지 진행한 브랜드 웹사이트 포트폴리오입니다.
캐릭터 맵파민을 중심으로 메뉴 소개, 3단계 맵기 챌린지, 이벤트 참여, 밀키트 주문, 가맹 안내까지 하나의 흐름으로 설계했습니다.

> 포트폴리오용 가상 브랜드 사이트입니다. 실제 김밥천국과 협업한 결과물이 아니며, 신청과 주문은 실제로 접수되지 않는 시연 기능입니다.

## 기획 의도

- 기존 김밥천국 사이트의 문제: 정보 위주의 단순한 구성, 브랜드 개성 부족, 모바일 사용성 부족
- 리뉴얼 방향: 매운맛이라는 하나의 키워드로 캐릭터, 색상, 콘텐츠를 묶어 기억에 남는 브랜드 경험 만들기
- 벤치마킹: 청년다방(랜딩 구성), 두찜(공지 모달), 스텔라떡볶이(메인 페이지)

## 페이지 구성

| 페이지 | 주소 | 내용 |
|---|---|---|
| 게이트 | `#gate` | 첫 방문 시 브랜드 / 가맹 중 선택 |
| 메인 | 기본 | 히어로, 협업 소개, 메뉴, 커뮤니티, 매장, 공지 |
| 브랜드 | `#brand` | 레드 이야기, 실비김치 협업 |
| 메뉴 | `#menu` | 카테고리 메뉴판, 맵기 단계 필터 |
| 이벤트 | `#event` | 3단계 챌린지, 이벤트 카드 4종 |
| 매장 찾기 | `#store` | 대전 지역 매장 4곳, 지도 |
| 공지사항 | `#notice` | 분류 탭, 펼침 목록 |
| 창업 | `#fr` | 가맹 안내, 창업 비용, 상담 신청 |
| 성우 오디션 지원 | `#voice` | 이메일 인증, 음성 파일/링크 제출 |
| 4행시 참여 | `#poem` | 첫 글자 고정 입력, 카드 미리보기 |
| 밀키트 상세 | `#kit` | 구성 선택, 수량, 금액 계산, 주문서 |
| 주문 완료 | `#order` | 주문 요약, 카드 동봉 안내 |

## 주요 기능

- **한 페이지 화면 전환**: 해시 주소(`#menu` 등)로 화면을 바꾸는 SPA 구조, 뒤로 가기 지원
- **첫 방문 공지 모달**: 포스터 슬라이드, 버튼에서 각 신청 페이지로 이동
- **이벤트 신청 양식**
  - 이메일 인증 시연 (6자리 번호, 3분 타이머)
  - 필수 항목과 동의 상태에 따라 제출 버튼 활성화
  - 같은 브라우저에서 같은 이메일로 중복 참여 방지 (localStorage)
- **밀키트 주문**: 구성과 수량에 따른 금액 자동 계산, 2만 원 이상 무료 배송, 주문서 패널, 주문 완료 화면
- **반응형**: 데스크톱 1920 / 모바일 390 기준
- **접근성**: 키보드 조작, 모션 줄이기 설정 대응
